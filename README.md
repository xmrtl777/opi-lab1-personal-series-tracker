Персональный сериал-трекер


Описание проекта

«Персональный сериал-трекер» — приложение для ведения персонального списка сериалов.
Приложение позволяет пользователю добавлять сериалы в список, отслеживать статус просмотра, устанавливать личный рейтинг, искать и фильтровать сериалы.


Основные возможности

- добавление сериалов;
- редактирование информации о сериалах;
- удаление сериалов;
- изменение статуса просмотра;
- установка рейтинга от 1 до 10;
- поиск сериалов по названию;
- фильтрация по статусу просмотра;
- сортировка сериалов;
- автоматическое сохранение данных.


Статусы просмотра

Приложение поддерживает следующие статусы:
- Запланировано
- Смотрю
- Просмотрено
- Брошено
