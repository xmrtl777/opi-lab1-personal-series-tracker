# Диаграммы поведения системы

## Персональный сериал-трекер

### Акторы
- **Пользователь** — основной пользователь системы.

### Основные Use Cases
- Добавление сериала с валидацией
- Изменение статуса просмотра
- Выставление рейтинга (1–10)
- Редактирование и удаление сериалов
- Просмотр списка с поиском, фильтрацией и сортировкой
- Автосохранение изменений

## Диаграммы последовательности

### 1. Добавление сериала (`add_series_sequence`)
Показывает процесс создания нового сериала: ввод данных, валидация,
сохранение со статусом «Запланировано» по умолчанию.

### 2. Изменение статуса (`change_status_sequence`)
Демонстрирует смену статуса просмотра
(«Запланировано» / «Смотрю» / «Просмотрено» / «Брошено»)
и автосохранение изменений.

### 3. Выставление рейтинга (`set_rating_sequence`)
Отображает проверку диапазона 1–10 и сохранение оценки.

### 4. Поиск и фильтрация (`search_filter_sequence`)
Комплексный сценарий: поиск по названию без учёта регистра
и фильтрация по статусу просмотра.
